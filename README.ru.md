# physis

[English version](README.md)

physis — исследовательский прототип инфраструктурного слоя для задач завтрашнего дня. Нагрузка просит **результат**: цель качества, срок, бюджет в джоулях, деньгах и граммах CO₂, места и юрисдикции, куда можно увозить данные. physis решает, **какой алгоритм, на какой физике, где и когда** даст этот результат с наименьшим углеродом, энергией, деньгами или временем, по живым прогнозам энергосистем, которые будут его питать.

Он работает на API Kubernetes (контракт остаётся, под ним меняется всё) и **не требует нод**: подложки — это агенты, которые сами забирают работу, а не машины, на которые назначают поды. У каждого результата есть подписанная квитанция в цепочке хэшей, которую любой может проверить без доступа к системе. Люди делегируют бюджеты подписанными мандатами, агенты действуют в их пределах.

Прототип знает одиннадцать физик: настоящий CPU и эмулированные цифровой и сверхпроводящий отжиг, обратимую логику, p-биты, когерентную оптическую машину Изинга, квантовый процессор (QAOA), аналоговые вычисления в памяти, фотонное ядро, нейроморфный чип и живую нейронную культуру как резервуар. Эмулированные подложки оцениваются по опубликованным цифрам или явным допущениям, у каждого числа указано происхождение (`docs/references.md`). На реальном железе модели предназначены для перекалибровки по квитанциям.

> Статус: исследовательский прототип. Прежде чем цитировать число, загляните в `docs/limitations.md`.

Документы, структура и запуск — в [README.md](README.md). Полная статья — `docs/article.ru.md`, дизайн — `docs/design.ru.md`, как проверялась статья — `docs/verification.md`.

Лицензия Apache 2.0. Данные энергосистем и эталонные задачи загружаются у их владельцев и остаются под их условиями.
